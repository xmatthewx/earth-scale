# Earth Scale

A drawing of how thin our living world is.

Earth, the moon, and a few familiar things — satellites, the space station, the
altitude planes fly at, the deepest part of the ocean — on one vertical axis at
true relative scale, pixel to km. Everything that has ever lived fits in a line.

**[See it →](https://matthewwillse.com/earth-scale.html)**

Drag the scale slider to change how many kilometers one pixel is worth. Low, and
you can see the thickness of the air; high, and the moon turns up, a long way
down. The point isn't the numbers — it's how far you have to scroll.

## Running it

Open `earth-scale.html` in a browser. There's no build step and nothing to
install; [rough.js](https://roughjs.com) and the type come from a CDN.

Everything else lives in `earth-files/` — `features.js` and `terra.js` hold what
gets drawn, `render.js` draws it.
